# RenStation Web

This is the React frontend for the RenStation platform, built using Vite, TypeScript, and Tailwind CSS.

## Architecture & Stack
- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router
- **State Management**: Zustand
- **Data Fetching**: TanStack Query (React Query) + Axios
- **Form Handling**: React Hook Form + Zod

## Getting Started
```bash
npm install
npm run dev
```
